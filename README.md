
# Plate with a Central Hole Static Structural FEA

Comparative static structural analysis of a **200 × 100 × 2 mm
stainless-steel plate** with a **20 mm central hole**, using Python
(Jupyter Notebook) and ANSYS Mechanical 2026 R1.

## Setup

-   Tensile stress: 40 MPa
-   Boundary condition: One end fixed
-   Mesh size: 2 mm
-   Analysis: Static structural

## Results

The two methods are compared using von Mises stress, total deformation,
factor of safety, and stress concentration around the hole.

## Tools

-   Python / Jupyter Notebook
-   ANSYS Mechanical 2026 R1

*For educational purposes only; this is not a certified design
assessment.*
